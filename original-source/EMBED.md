# Dog Academy quiz embed

Add this where the quiz should appear on the host page:

```html
<div data-dog-academy-breed-quiz></div>
<script
  async
  src="https://dog-breed-match-quiz.amandakayestein.chatgpt.site/embed.js"
></script>
```

The script creates an accessible quiz frame and automatically adjusts its height as the visitor moves through the questions and results. If the quiz is later hosted on `dogacademy.org`, replace only the domain in the script URL.
